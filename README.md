# 🎓 Notion Học Tập - Workspace Ôn Thi & Ghi Chú Thông Minh

Trang web ghi chép và ôn tập học tập cá nhân lấy cảm hứng từ giao diện Notion, tích hợp các phương pháp học tập khoa học: **Active Recall**, **Spaced Repetition**, **Cornell Note-Taking** và **Kỹ thuật Pomodoro**.

---

## ✨ Tính Năng Nổi Bật

- 📝 **Trình Soạn Thảo Khối (Block Editor)**:
  - Menu gõ phím tắt `/` trực quan.
  - Hỗ trợ Tiêu đề (H1, H2, H3), To-do list, Gạch đầu dòng, Trích dẫn, Khối mã code.
  - **Khối Thu Gọn (Toggle)**: Ẩn/hiện đáp án phục vụ tự kiểm tra Active Recall.
  - **Công thức Toán học KaTeX**: Gõ công thức Toán, Lý, Hóa chuẩn LaTeX trực quan.
  - **Khối Callout**: Làm nổi bật định lý, công thức với icon tùy chỉnh.
- 🍅 **Đồng Hồ Pomodoro Tập Trung**:
  - Chu kỳ 25 phút học / 5 phút nghỉ ngắn / 15 phút nghỉ dài.
  * Tích hợp chuông báo Web Audio và theo dõi số phiên học.
- 🎴 **Chế Độ Ôn Flashcard 3D**:
  - Tự động thu thập câu hỏi từ bài học để ôn tập toàn màn hình.
  - Lật thẻ 3D và đánh giá mức độ nhớ theo Spaced Repetition (Khó - Vừa - Dễ).
- 📋 **Bảng Kế Hoạch Ôn Thi (Kanban Study Board)**:
  - Quản lý tiến độ học tập 4 cột: *Cần học*, *Đang ôn tập*, *Ôn lặp ngắt quãng*, *Đã thành thạo*.
  - Hỗ trợ kéo thả trực quan.
- 🎨 **Giao diện chuẩn Notion**:
  - Hỗ trợ Dark Mode (Giao diện tối) & Light Mode.
  - Đổi ảnh bìa Gradient, đổi icon Emoji cho từng trang.
  - Tìm kiếm nhanh tức thì với tổ hợp phím `Ctrl + K`.
- 💾 **Lưu Trữ & Xuất File**:
  - Tự động lưu trên trình duyệt (`LocalStorage`).
  - Xuất ra file Markdown (`.md`), in PDF hoặc sao lưu file JSON.

## 🚀 Hướng Dẫn Sử Dụng
